# numeria
Образовательная платформа для формирования и развития профессиональных компетенций у студентов-экономистов.

Документы пилота:

- `docs/spec-product.md` — учебный состав, прогресс, кризисы, оценка
- `docs/spec-backend.md` — сервисы и границы
- `docs/spec-backend-schema.md` — таблицы
- `docs/spec-backend-api.md` — контракты API
- `frontend/spec.md` — клиент
- `frontend/spec-case-window.md` — окно кейса на карте
